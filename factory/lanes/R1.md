# Lane R1 — brief

The whole brief for the Home lane of the redesign (`factory/REDESIGN.md`). The launch prompt is the block below. It works
as a cloud session (environment `Shifty`, starts from `main`) and as a local session on Bill's Mac in its own git worktree.

```
LANE R1 — Home: clock in, live session, recap, sync status, ribbon · app SHIFTY (mafiabossbill/shifty)

AGENT: frontend-engineer. You are this agent for the whole session: read `.claude/agents/frontend-engineer.md` first and
work under that contract. You are one lane of a larger redesign. Four other lanes (R2 Sessions, R3 Insights, R4 Companion,
R5 Settings) run at the same time on other files. Do not start other sessions.

START: the default branch `main` is PRODUCTION. Never base work on it and never open a PR into it. Your branch must start
from the integration branch `redesign`:
- Cloud session (you began on `main` or on a branch cut from it): `git fetch origin redesign`, keep your branch name and
  `git reset --hard origin/redesign` before any work.
- Local session in its own git worktree, on a branch already cut from `redesign`: `git fetch origin redesign`, then
  `git merge-base --is-ancestor origin/redesign HEAD`. If that fails and you have no commits of your own yet,
  `git reset --hard origin/redesign`.
Either way `factory/handoffs/redesign-r0.md` must exist once you are on it. If it does not, the foundation is not merged
yet: stop and say so. `npm ci` first. At the end open a PR with base branch `redesign`. Never merge, force-push to a shared
branch, or deploy.

ON BILL'S MAC (skip this block in the cloud):
- Work only inside your own worktree folder. Other lanes use other folders. Never switch branches, stash, reset or edit
  anywhere else, the main checkout included.
- There is no `.env` file and none is to be created. The app runs without a backend in device mode; `/?demo=1` shows
  generated data.
- Chromium: `export E2E_CHROMIUM_PATH="$(ls -d ~/Library/Caches/ms-playwright/chromium_headless_shell-*/*/chrome-headless-shell | tail -1)"`,
  or `npx playwright install chromium` if nothing is cached.
- Your ports, because other lanes run servers at the same time: dev server 3011, screenshots 4311.
  `npx next dev -p 3011` · `E2E_BASE_URL=http://localhost:3011 npm run test:e2e` · `npm run design:shots -- --port 4311 --only /design/screens/home`
- Stop every server you started before you finish.
In the cloud: Chromium is usually `/opt/pw-browsers/chromium`; the default ports are fine.

READ FIRST, in this order: `factory/REDESIGN.md` (the plan, decisions R-D1…R-D6, ownership, the marker rule),
`factory/handoffs/redesign-r0.md` (all of it: §3 renames, §4 the mechanical edits already made in your files, §5 how to add
a gallery page, §9 asks), `factory/PRODUCT_BLUEPRINT.md` § Screens ("Rules every plan shares", then "`/` Home (R1)" and the
"Shell parts owned by R1" paragraph), `factory/DECISIONS.md` D11 to D21, `docs/factory/docs/UI_UX_STANDARD.md` (§1 the

`factory/SCREEN_LANES.md`, `CLAUDE.md`. Then open `/design` in development: it shows the whole system.

GOAL: Redo the look of Home and of the three shell parts R1 owns (sync pill and sheet, active ribbon, demo banner) from the
design system lane R0 installed. Look only (R-D1): every block, action, URL, piece of copy and behaviour stays. Build each
screen from its plan in `factory/PRODUCT_BLUEPRINT.md` § Screens and show every state the plan lists in the gallery.

ACCEPTANCE:
1. Every file you own that carries `// design-ok-file: awaiting redesign lane R1 (home)` is converted and the marker is
   removed. Today that is 9 files: `src/components/home/active-hero.tsx`, `clock-in-hero.tsx`, `home-screen.tsx`,
   `recap-sheet.tsx`, `side-cards.tsx`, `src/components/session/active-ribbon.tsx`, `src/components/sync/demo-banner.tsx`,
   `sync-sheet.tsx`, `sync-status.tsx`. No retired class, variant or prop is left in any file you own (handoff §3;
   `tests/design.test.ts` enforces it once a marker is gone).
2. The ribbon, the sync pill and the demo banner sit in the shell on every page: convert them first. `SyncStatus` draws
   its own loading placeholder with retired classes; fix it.
3. Home follows its plan. In short: idle, **Clock in** is the one solid button (`lg`, full width on phones) with
   "Goal 16h net · {zone}" under it; working, **Clock out** is solid and Start a break is outline; on a break, **End break**
   is solid and Clock out drops to outline. Net worked is the one `text-display` number. Progress to the goal is a
   `ProgressBar` with the figures in words. Must change (from the plan): the ring, its halo and the round CLOCK IN go; the
   64 to 88px timer becomes `text-display`; capital eyebrows become captions; the hero card and the side cards lose their
   boxes and glow; nudges are a sentence with a dismiss button, not tinted cards; the XP box in the recap becomes a plain list.
4. Nothing you own imports `ProgressRing` any more (`src/components/ui/progress-ring.tsx` is retired and is deleted after R1
   and R2 land). Use `ProgressBar value overage label valueText`.
5. Gallery: `src/lib/design-gallery/home.ts` replaces `awaiting("R1")` for `/` with a gallery entry, and there is a page
   under `src/app/design/screens/home/` for every state the plan lists (loading, first run, idle, the `?action=clock-in`
   prompt, working, on a break, over the goal, crossed midnight, the location states, nudge shown, storage blocked, long
   title, demo banner, recap sheet with and without undo left), plus the sync sheet and the ribbon. `/dashboard` keeps its
   exemption. Sample helpers go in `src/components/design/home-samples.ts`. A state the store's public actions cannot
   reach is listed in the handoff with the reason; it is not a licence to edit the store.
6. Behaviour unchanged. Earlier QA fixes still hold: the recap's per-day split and the midnight line add up to the net
   shown, one `h1` a page, 44px touch targets on phones, a double tap on Clock in makes one session.
7. `npm run check:full` green; `npm run design:check` 0 errors; every `design-ok` you add has a real reason and is listed
   in the handoff.
8. Browser journeys (`npm run test:e2e` against a local dev server, all three widths): everything that passes on untouched
   `redesign` still passes. Nine tests already fail there and are not yours: `offline.spec.ts` (2 tests × 3 widths) and
   `sweep: public pages` (× 3). Do not fix, skip or delete them.

YOU OWN: `src/components/home/**`, `src/components/session/**`, `src/components/sync/**`, `src/app/(app)/page.tsx`,

ENV VARS AVAILABLE: none are needed. Never print, copy or commit a value from the environment.

DONE MEANS:

FINAL REPORT (≤200 words): branch, PR link, verification, open risks.
```
